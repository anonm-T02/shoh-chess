GitHub Pages'ga chiqarish:
1. GitHub'da yangi PUBLIC repository yarating, masalan: shoh-chess
2. Shu papkadagi BARCHA fayllarni repository ROOT qismiga upload qiling
3. Commit changes bosing
4. Repository -> Settings -> Pages
5. Build and deployment:
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
6. Save bosing
7. GitHub bir necha daqiqada sayt URL beradi:
   https://USERNAME.github.io/REPOSITORY-NOMI/

Custom domain keyin:
Repository -> Settings -> Pages -> Custom domain
